# PT Serif

Начертания Regular и Bold скопированы без изменений из `E:/GPT/SuperMANCH/assets/fonts/pt_serif/` вместе с `OFL.txt`. Авторские сведения и условия распространения находятся в этом файле. Шрифты содержат кириллицу и поставляются со сборкой, поэтому системная установка не требуется.

В SM2 используются для заголовка боя, развёрнутых описаний и всплывающих подсказок. Короткие игровые показатели и кнопки используют прежний шрифт интерфейса.
