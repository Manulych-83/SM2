## Исправления, найденные при проверке

Первый controls обнаружил несовпадение обработки физического Escape: инвентарь/развитие опирались только на встроенный ui_cancel. Исправлено общей функцией возврата; исходный тестовый процесс после ошибки остановлен по точному PID, его логи сохранены в `.local/ui14/controls`. Во втором прогоне тест пытался проверить пси-кнопку без изучения способности; добавлены настоящие упражнения/покупка через существующий helper. Этот прогон завершён watchdog с ошибкой и не засчитан. Финальный сценарий проходит.

Исторический start_menu UI 8 исправлен по уже действующему контракту UI 9: перед нажатием Resume закрывается окно дополнительных режимов; валидная резервная копия должна восстанавливаться, а при повреждении обоих файлов открывается выбор кампаний с сохранением живой сессии. Проверены оба пути, защита байтов старого профиля и повторный запуск. Ожидания не маскируют изменение домена: игровая политика резервных копий в этом этапе не изменялась.
