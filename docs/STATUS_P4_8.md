## Проверенное поведение

- Осмотр даёт 50 опыта Поиска и 10 опыта Восприятия только текущему герою. Прочие направления и спутник этой награды не получают; учебные упражнения не засчитываются.
- Повторный осмотр, закрытая точка, активный бой, отсутствие тела, переполнение XP/тайника отклоняются без частичной награды. Точный предел опыта допустим.
- Два осмотра автоматически повышают Поиск до уровня 2 без расходования опыта. Лечение и бой не прибавляют опыт этого навыка.
- Подделанный опыт, не согласованный с историей, отклоняется без изменения текущей сессии. Старые/новые форматы и изменённые награды не подменяют друг друга.
- Сохранение активного боя сохраняет расширенные направления в исходном состоянии встречи. После загрузки следующий шаг и весь итоговый снимок совпадают.
- Реальная последовательность проверяет осмотр → бой/рану → лечение найденными средствами → второй осмотр → конец жизни → чистое тело → следующую встречу → осмотр оставшегося места. Каждая жизнь получает только свою практику; знания и спутник сохраняются, собранные точки не обновляются.
- В UI нажаты реальные кнопки осмотра, сохранения, продолжения, лечения и воплощения. Проверены видимый прирост, уровень 2, ноль у нового тела и недоступность повторного сбора.
