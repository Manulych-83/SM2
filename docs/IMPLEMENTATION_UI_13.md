# UI 13 — настройки изображения и памятка управления

12 сентября 2026, **0.8.19-ui.13**. Пользователь выбрал «Сначала удобство: настройки и управление» вместо перехода к первому цельному походу. Реализован отдельный экран из главного меню и лагеря.

## Изображение

- Полный экран или окно. Базовый режим остаётся эксклюзивным полноэкранным; он использует размер текущего монитора.
- Размер клиентской области окна: 2560×1440, 1920×1080, 1280×720. Если окно не помещается, размер пропорционально уменьшается с учётом рабочей области и существующего минимального размера Godot. Выбор размера отключён в полноэкранном режиме.
- Вертикальная синхронизация: включена/выключена.
- Базовые настройки заполняют форму исходными значениями и требуют последующего применения.

Редактирование формы не меняет изображение. «Применить» запоминает текущий режим, размер, позицию, borderless и vsync, включает предварительный просмотр на 15 секунд. «Оставить и сохранить» записывает настройки; «Вернуть прежнее», Escape, уход со страницы или истечение таймера возвращают предыдущие параметры. Во время проверки форма заблокирована. При ошибке записи изображение тоже возвращается назад с сообщением.

Базовая композиция 2560×1440, KEEP и масштаб 1.6 сохраняются. Для обхода воспроизведённого сбоя Godot/Windows начальная ширина прямоугольника восстановления окна в project.godot изменена с 2560 на 2559. Это не разрешение полноэкранного изображения и не ширина viewport. Без этого на данной машине переход из эксклюзивного полного экрана обратно в окно немедленно возвращался в режим 4. Аналогичное поведение описано в [Godot issue #120283](https://github.com/godotengine/godot/issues/120283); обход проверен реальными переключениями.

## Хранение и архитектура

`Sm2DisplayPreferences` в infrastructure хранит проверенные mode/resolution/vsync в отдельном `user://display_settings.cfg`, версия 1. Файл не является сохранением кампании. Отсутствие файла возвращает базовые значения без записи; неполный/неподдерживаемый набор отклоняется. Main применяет только успешно прочитанные существующие настройки при запуске. Ошибка файла не меняет кампанию; экран сообщает о базовых значениях.

`Sm2DisplaySettings` в presentation применяет и возвращает параметры Window/DisplayServer. `Sm2SettingsScreen` хранит черновик, таймер и подтверждение. Main открывает страницу settings и возвращает menu либо life, сохраняя тот же объект сессии. Это не дополнительная пауза симуляции: настройки открываются из меню/лагеря, где боевой экран уже закрыт. Возврат к идущему бою остаётся прежним маршрутом.

Запись ConfigFile обычная, без заявления об аппаратной атомарности. При неполной записи следующий запуск отвергнет невалидный набор и использует базовое поведение. Подтверждение параметров не вызывает сохранение кампании, загрузку мира или игровые команды.

## Управление и границы

`content/presentation/controls.json` содержит памятку фактически реализованных действий: ЛКМ/ПКМ по полю, цифровые клавиши 1–9 текущей группы, осмотр портретов, прокрутка, Escape на отдельных экранах, кнопки управления ходом. Памятка не вводит новых привязок. Прицельные действия выбирают цель, способности на себя могут выполняться сразу — это обозначено.

Переназначение клавиш, изменение масштаба UI, звуковые настройки, графические пресеты и выбор монитора не входят. Рамки без треугольников, оформление в прежнем бронзовом стиле. Domain, игровые каталоги и форматы кампаний не меняются. Цельный первый поход этим выбором отложен. Приёмка — [STATUS_UI_13.md](STATUS_UI_13.md). Коммит и публикация отдельно.
