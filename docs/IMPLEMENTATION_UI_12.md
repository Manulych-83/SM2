# UI 12 — журнал путешествия

12 сентября 2026, **0.8.18-ui.12**. Продолжение оформления основного игрового цикла: из лагеря доступен «Журнал путешествия».

Экран показывает действительную последовательность лагерных действий и завершений боёв, новые события сверху. Есть поиск по названию/месту, фильтр группы и страницы по 30 записей. Внутри страницы — прокрутка. Группы и подписи событий вынесены в `content/presentation/journal.json`; название предмета, упражнения, узла или места берётся из соответствующего каталога.

## Достоверность

История сессии хранит команды, а не готовый текст событий. Принятая команда может прерваться из-за кровопотери. Поэтому `Sm2JournalView` создаёт отдельную сессию **без хранилища** и с тем же исходным миром. В одном проходе применяет исторические лагерные команды через прежний `_camp(..., true)`, проверяет закрытые боевые снимки через `_check_battle` и использует прежний `_finish` только на временной сессии. Для активного боя проверяется его снимок и ревизия без settlement.

После каждого события проекция снимает фактическое место и календарные секунды, окончание жизни героя, число появившихся уникальных предметов. Действие, на котором жизнь закончилась из-за состояния тела, обозначено как прерванное. Количество новых предметов считается по ID, а не разнице общих количеств; оно не выдаётся за автоматический сбор. В конце восстановленный world.capture обязан совпасть с текущим миром по каноническому отпечатку. При несовпадении показывается ошибка без частичной истории и без изменения живой игры.

Чтение не вызывает new_game, не создаёт новый идентификатор мира, не использует настоящее хранилище и не публикует временное состояние. Опыт, находки и исходы живой сессии не применяются повторно. Записи сохраняются через уже существующую историю, новых полей снимка и миграций нет.

## Представление и границы

`Sm2JournalScreen` строит проекцию один раз при открытии; поиск, фильтры и страницы работают по отделённым данным без нового проигрывания истории. Закрытие кнопкой или Escape возвращает прежний лагерь. Состояние фильтров локальное; при следующем открытии журнал обновляется.

Даты — существующий игровой календарь, не реальное время компьютера. Начало и итог сражения — отдельные записи; каждый удар не становится событием этого экрана, для этого остаётся боевой журнал. Новых заданий, наград, экспорта дневника и архива сверх существующего лимита истории 4096 нет. Открытие восстанавливает всю историю; страницы ограничивают количество элементов интерфейса, а не стоимость восстановления. Асинхронное индексирование большой кампании и снятие лимита относятся к будущей работе.

Domain, игровые каталоги, правила, схемы и инфраструктура хранения не меняются. Добавлены application-проекция, экран, presentation JSON и кнопка в лагере. База QHD 2560×1440/KEEP/scale 1.6, бронзовые рамки без треугольников. Приёмка — [STATUS_UI_12.md](STATUS_UI_12.md). Коммит и публикация отдельно.
