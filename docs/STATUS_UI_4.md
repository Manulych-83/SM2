## Исправления промежуточных прогонов

- `hud1` выявил неверное свойство Button для вертикального выравнивания. Заменено отступами его стилей. Для элементов до присоединения к сцене стили берутся из темы владельца, чтобы не подставлять стандартную тему.
- Проверка геометрии ранее учитывала скрытые ресурсные подписи при вкладке «Детали». Теперь скрытые элементы пропускаются; границы видимых элементов продолжают проверяться.
- Прогоны `hud2`/`display1` выполнили сценарии, но завершились с ошибками освобождения ресурсов. Причина — взаимные RefCounted-ссылки layout↔hud. Обратная ссылка заменена доступом через узел владельца. Эти прогоны не приняты; последующие завершились без ошибок.
- Уточнена синхронизация заголовка контекстной карточки и подробностей при наведении на другого бойца. Нижняя активная карточка от этого осмотра независима.
