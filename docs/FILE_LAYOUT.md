# Где хранятся файлы SM2

Единственный корень создаваемых агентами файлов проекта — **E:\GPT\SM2**. Правило действует для всех исполнителей, проверок и временных материалов.

| Каталог внутри проекта | Назначение |
|---|---|
| src/, scenes/, content/ | Исходники, сцены и контент игры |
| docs/ | Решения, архитектура, инструкции и результаты этапов |
| outputs/ | Готовые отчёты и изображения для просмотра |
| tests/, tools/ | Проверки и инструменты проекта |
| builds/ | Собранная игра |
| .godot/ | Создаваемый Godot кеш проекта |
| .local/ | Локальные журналы, результаты проверок, рабочие заметки и временные данные |
| .local/runtime/ | Служебные данные процессов, запущенных инструментами проекта |

Документы, изображение стартового экрана и рабочие заметки из прежней папки задачи Codex перенесены сюда. При переносе сверены SHA256. Запись о переносе находится в `.local/file-location/transfers.json`; прежний отдельный отчёт исполнителя ядра — в `.local/file-location/domain-agent-review.json`.

После закрытия ранее запущенной игры её прежние журналы и кеши также перенесены в `.local/runtime/appdata/SM2` со сверкой SHA256. Игровых сохранений в исходной папке не было. Запись о переносе — `.local/file-location/runtime-transfer.json`. Новый запуск через инструменты проекта проверен с этим расположением данных; проверки и экспорт после изменения также прошли, см. `.local/file-location/runtime-acceptance.json`.

Не использовать для новых материалов проекта Documents/Codex, общую временную папку Windows или корень профиля пользователя. Установленные программы можно читать и запускать из прежнего расположения; переносить установку Godot для этого не требуется.

Запуски проверок используют отдельный каталог данных внутри проекта. Способ запуска игры и точный путь сохранения описаны в `LAUNCH_AND_CHECKS.md`.

## Актуальные документы после уточнения концепта

1. [WORLD_CONCEPT.md](WORLD_CONCEPT.md) — подтверждённые правила мира, Души, воплощений и опыта; открытые вопросы отдельно.
2. [DECISIONS.md](DECISIONS.md) — реестр решений и история согласованных реализаций.
3. [SOUL_BODY_PROGRESSION_ARCHITECTURE.md](SOUL_BODY_PROGRESSION_ARCHITECTURE.md) — проект владения состоянием, развития, подключения к бою и сохранения.
4. [DEVELOPMENT_ROADMAP.md](DEVELOPMENT_ROADMAP.md) — предложенные следующие срезы и критерии готовности.
5. [ARCHITECTURE_PLAN.md](ARCHITECTURE_PLAN.md) — исходный анализ тактической основы и общие принципы; прежняя кампания компании отмечена как исторический план.

IMPLEMENTATION_M*.md и STATUS_M*.md описывают реально сделанное, со своими техническими именами и версиями. Новый концепт не переименовывает их задним числом. Материалы проверки документационного шага: `.local/concept-architecture-20260910`, итоговый отчёт — `outputs/concept-architecture-20260910`.
