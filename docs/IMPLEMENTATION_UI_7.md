# UI 7 — карта и лагерь

12 сентября 2026. **0.8.13-ui.7**. Пользователь подтвердил общий экран карты/лагеря в существующем стиле, без новых правил путешествий.

## Рабочий экран

В актуальном «Походе к руинам» прежняя длинная страница заменена тремя областями: отряд, карта/переходы/рекомендация, местные занятия. Сохраняются полноэкранные 2560×1440, canvas_items/KEEP и scale1.6. Бронзовые рамки и пергамент переиспользованы; треугольных украшений нет.

Карта показывает три действующих места и соединения из региона. Нажатие места выбирает его описание без команды миру. Текущее место отмечено кольцом, осматриваемое — нажатым состоянием кнопки; посещение показано в описании и подсказке. Кнопки переходов считают время из **текущего** места; осмотр другой точки не открывает её удалённые занятия. Дорога запускается отдельной явной кнопкой и использует прежние 30/90/120 минут. Случайных встреч нет.

Схема не является географической картой с местностью, туманом войны или движущимся по ней персонажем. Координаты и короткие обозначения в `content/presentation/region_map.json` относятся только к представлению; дороги и длительности берутся из игрового каталога. Все места известны, посещения сохраняются прежним миром.

Отряд: состояние героя/спутника, кровь, кровотечение, число неработающих функций, масса и осмотр местного тела. Удалённое погибшее тело обозначено местом, без кнопки удалённого доступа. Без героя есть пояснение о Душе. В идущем бою лагерные показатели крови и функций не выдаются: отображается переход обратно в сражение.

Занятия фильтруются действительным местом. В лагере — упражнения и доступные местные улучшения, в руинах — осмотры и генетический препарат, в анклаве — комплект импланта и установка. Внутри группы доступные действия стоят первыми; недоступные сохраняют объяснение. Награды, длительности и эффекты берутся из каталогов. Перевязка и предметные процедуры открываются через уже работающий экран тела/инвентаря. Новых способов лечения не введено. Находки остаются на земле до переноса.

Развитие, сохранение, загрузка, меню, рекомендованный маршрут, камень в тайнике, завершение жизни с подтверждением и выбор местного носителя продолжают прежнюю сессию. Первое сражение по-прежнему требуется перед ручным завершением жизни. Подтверждение запоминает исходную команду: изменившаяся ревизия требует повторного осмысленного действия.

## Разделение ответственности

- `Sm2CampView` — новая отделённая application-проекция: места, маршруты, отряд, доступные в локации виды занятий и носители. Не меняет время, состояние, ресурсы, ID или RNG. Причины берёт из `world.check`.
- `Sm2RegionMap` — только рисование схемы и сигнал выбора ID места. Не получает игровую сессию.
- `Sm2CampScreen` — размещение, оформление, локальный выбор и команды с захваченными world/revision/body/incarnation. Исполнение проходит общий `session.act`; старый снимок кнопки не создаёт свежую команду автоматически.
- `Sm2LifeScreen` выбирает новый вид только при Survival с тканевыми слоями. Старые профили сохраняют прежние страницы. Общий помощник исполнения принимает готовую команду; подтверждение завершения жизни использует его и в прежних профилях.

Прежняя `Sm2JourneyGuide` и её проверяемая рекомендация переиспользованы. Return из завершённого боя не начинает следующую встречу сам. При уменьшенной логической ширине отряд переносится в правую прокрутку. Изменение размера перестраивает только видимый лагерь; не закрывает открытый инвентарь и не меняет мир.

Domain, игровые каталоги, схемы сохранений и слоты не менялись. Нового режима/кампании не добавлено. Огромная карта, произвольные маршруты, фракции, торговля и дальнейшие механики вне этапа. Проверки — `STATUS_UI_7.md`.
