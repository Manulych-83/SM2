# Profile 1 — результат компактного боевого профиля

13 сентября 2026. **0.8.30-profile.1**, Godot 4.7.2. Реализован профиль неизменного развития для боёв с ростом после завершения. Текущие команды используют подготовленные параметры и короткие счётчики практики; публичные снимки и загрузка сохраняют полный формат. [Контракт](IMPLEMENTATION_PROFILE_1.md).

## Измеренный результат

Обычный и большой профили прошли по 46 реальных команд до и после изменения. **Все события/хеши каждого шага, начальные и конечные снимки, таблицы итогов совпали.** Файлы initial/final/results совпадают побайтово. Правила роста и результаты боя не менялись.

| Операция | Обычный профиль: до → после | Большой профиль: до → после |
|---|---:|---:|
| Действия с практикой героя, без завершающего | 29–64 → 27–70 мс | 212–232 → 107–127 мс |
| Медиана этих действий | 60 → 56 мс | 221 → 113 мс |
| Начало боя | 72 → 77 мс | 1930 → 2030 мс |
| Первое сохранение активного боя | 114 → 122 мс | 2292 → 2467 мс |
| Загрузка активного боя | 122 → 116 мс | 2565 → 2654 мс |
| Завершающее действие | 220 → 234 мс | 1880 → 1851 мс |
| Сохранение завершённого боя | 601 → 616 мс | 5757 → 6176 мс |

На большом тестовом теле медианное время действий с практикой уменьшилось примерно на **49%**. На обычном персонаже выигрыш небольшой и сопоставим с колебаниями замеров. Сохранения не ускорились; начало/загрузка дополнительно собирают профиль. Это отдельные измерения на этой машине, не гарантированные задержки и не ускорение всего игрового процесса вдвое.

Большой профиль содержит 200 направлений, 10000 определений и искусственно изученные узлы; это не готовый игровой контент или приёмка огромной кампании. Обычный профиль использует текущий контент без искусственного большого дерева. Промежуточный большой прогон без замены структурного обхода дал выбранные атаки около 133–138 мс; итоговые числа выше относятся к завершённому изменению.

Отчёты: [обычное сравнение](../outputs/profile-1/comparison-ordinary.json), [большое сравнение](../outputs/profile-1/comparison-large.json). Исходные замеры и снимки лежат рядом в baseline-ordinary, baseline-large, final-ordinary, final-large.

## Проверки

Набор `combat_profile` прошёл **403 проверки**: обычные/усиленные гибриды и щит, расчёты силы и стоимости, прогнозы и реальные события, защита отдельных копий, отказ при попытке загрузить внутреннюю запись, неверные поля/типы/счётчики, равенство структурного бюджета ровно у предела, полный бой против прежних вычислений. После загрузки собирается новый профиль, внутренняя доверенная привязка не переносится из файла.

В первом сравнительном стенде после сохранения различался архив: запись была выполнена только у быстрого варианта. Исправлен стенд — оба варианта выполняют одинаковые запись и загрузку; сравнение полного состояния не ослаблено. Финальный прогон проходит.

Всего прошли **4110 проверок ядра и 886 проверок интерфейса**, все коды выхода 0. Общая регрессия и UI перечислены в [checks.json](../outputs/profile-1/checks.json). Проверены рост после боя, старые режимы развития/псионики/гибридов, ИИ, анатомия, checkpoint, сохранения, полный поход, итог и переходы интерфейса. UI выполнялся с рендером; актуальный QHD-снимок итогов просмотрен, компоновка не изменялась.

## Сборка и воспроизведение

`tools/export_game.ps1 -RuntimeRoot .local/profile-1/export` завершился с кодом 0. Собран **builds/SM2.exe** версии 0.8.30-profile.1. Проверочный запуск упакованных ресурсов и отдельный запуск EXE на 120 кадров завершились с кодами 0 без ошибок Godot. [Версия, хеш и журналы](../outputs/profile-1/build.json).

Упакованная сборка проверяет старый завершённый поход с резервной копией, архивный исход после второго воплощения, новую кампанию, наличие профиля в новом бою и сохранение/загрузку реально накопленной практики. Пользовательские сохранения не использовались: только тестовые копии внутри `.local/profile-1`.

Воспроизведение: `tools/run_checks.ps1 -Suite combat_profile`; прежние наборы через `-Suite`; `tools/run_ui_checks.ps1 -Suite battle_results` и остальные указанные в сводке; `tools/check_combat_io.ps1 -Ordinary` и без флага. Для каждого прогона задавать отдельные RuntimeRoot/OutputDirectory внутри проекта, чтобы сохранять прошлые результаты.

Оставшиеся расходы: полное копирование лагерного мира, анатомии и вещей, прочие проверки состояния, завершение и файловые операции большого боя. Результат не означает готовность большого мира или мгновенных сохранений. Коммит/публикация не выполнялись.
