# P4.2 — результаты проверки лаборатории характеристик

11 сентября 2026. Godot 4.7.2, версия проекта 0.5.5-p4.2. **PASS** в пределах учебного контракта [IMPLEMENTATION_P4_2.md](IMPLEMENTATION_P4_2.md). Сводка — [acceptance.json](../outputs/p4_2/acceptance.json).

## Реализовано

В меню добавлены «Восемь характеристик». У каждой собственные опыт, уровень, упражнение и одноразовый узел. Четыре обычных упражнения дают 100 опыта и уровень11. Покупка стоит70, оставляет уровень11 и доступный остаток30. Остальные направления не получают опыта.

Силовой стенд даёт +5 только при подъёме учебного груза. Исходная Мощь10 позволяет выполнить упражнение со стендом при требовании12, но собственный уровень остаётся10, узел недоступен. После своей тренировки и узла итоговая Мощь12 позволяет поднять груз без стенда. За выполненное упражнение даётся его награда; отказ не меняет состояние.

Использованы общие каталог, координатор практики, правила покупки, проверка снимков и прикладная сессия. Новый профиль отдельно разрешает учебные операции и условия; прежний профиль сохраняет строгие операции и собственный формат. Слот `p4_attribute_lab` в `user://attributes` отделён от P1 и игровых сохранений «Пути героя».

## Продолжение после закрытия и запуск

После завершения UI-процесса отдельный Godot-процесс загрузил тот же слот без создания нового мира: Мощь earned110/spent70, остальные семь направлений earned25/spent0, знание Души сохранено. Следующее упражнение выполнено; повторная загрузка вернула сохранённое состояние, поскольку промежуточное действие не сохранялось автоматически. Результат — [restart.json](../outputs/p4_2/restart.json). Это межпроцессная проверка сессии Godot; взаимодействие с лабораторией внутри экспортированного EXE отдельно не автоматизировалось.

Экспорт выполнен `tools/export_game.ps1 -RuntimeRoot .local/p4_2/export-runtime`. Журнал `.local/logs/export-20260911-094927-644-85f1fd62.log`. SHA256 `builds/SM2.exe`:

Окружение задано через Invoke-Sm2Process/RuntimeRoot, APPDATA/LOCALAPPDATA/TEMP/TMP остаются внутри `.local/p4_2/exe-runtime`. Свидетельство — `.local/p4_2/exe-launch.json`.
