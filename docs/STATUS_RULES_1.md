## Стоимость запроса

[measure.json](../outputs/rules-1/measure.json) содержит пять парных измерений по 1000 запросов: прежняя функция из отдельного измерительного файла и новый расчёт с полным объяснением, один действующий эффект ослабления и колеблющаяся мораль. Значение каждого запроса проверяется по эталону 54. Порядок в каждой паре — прежний, затем новый; это небольшой локальный замер, не полноценный сравнительный бенчмарк всей игры.

Добавление проверки/расшифровки повышает цену запроса: приблизительно 0,014 мс → 0,046 мс в первоначальном замере. Финальные сырые значения находятся в JSON. Это **не оптимизация скорости**. Полное время команды, сохранения и большого боя этим измерением не оценивалось. При расширении числа одновременно действующих правил потребуются отдельные замеры; библиотека сейчас проверяет переданную последовательность при запросе, не компилирует все будущие условия заранее.

## Исправленные промежуточные ошибки

- Первый запуск обнаружил несовместимость нетипизированного массива из условного выражения с `Array[String]`. Исправлено явным `assign`, проверки повторены.
- Первый UI-маршрут тренировал только псионику, но ожидал прибавку ближнего боя. Игровые правила сохранили; для проверки отображения взят явно подготовленный исходный герой с melee XP, как в тестах итогов. Это тестовая заготовка, не начисление опыта в игре.
- При самопроверке числовой предел расширен с 10^12 до 8×10^12: прямые вклады большого развития и боевой множитель могут превысить первоначальное значение. Произведение при максимальном допустимом проценте остаётся в 64-битном диапазоне. Повторены профильные проверки и экспорт.
- Первый прогон упакованных ресурсов скопировал занятый третий тестовый слот и встретил прежнее подтверждение замены кампании. Финальный стенд подготовлен с двумя старыми слотами и свободным третьим; UI-политику не меняли.
