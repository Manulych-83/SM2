## Сохраняемые решения

- Одиночная ПК RPG, пошаговые гексы, герой и управляемые спутники. Географически разные технологии после катастрофы; генетика, кибернетика и псионика совместимы.
- Душа сохраняет знания, мир не перезапускается. Новое воплощение — свежий обычный человеческий труп без улучшений и старой практики; первый пример оживает здоровым. Вещи остаются в мире/при прежнем теле.
- Герой: каждое направление получает свою практику; накопленный XP повышает уровень автоматически. Узлы оплачиваются доступным XP нужных направлений без снижения уже полученного уровня. В новых боях практика копится, рост применяется после боя. Спутники: общий личный XP за атаки/промахи/реакции, автоматический рост.
- Восемь характеристик: Мощь, Моторика, Стойкость, Интеллект, Восприятие, Воля, Резонанс, Синхронизация. Формулы брать из существующего домена.
- QHD 2560×1440, KEEP, scale 1.6, логические 1600×900. Тёмные панели, тонкая бронза, PT Serif; без треугольных украшений.
- Вместимость без пространственной сетки. Перенос/снаряжение вне боя; перевязка также в бою. Объём условный, не литры; общего лимита веса героя не придумывать.
- `content` / domain / application / infrastructure / presentation разделены. Сохранять форматы, fingerprint, ревизии и атомарность команд. Проверки отдельных больших каталогов не доказывают готовность огромной кампании целиком.
