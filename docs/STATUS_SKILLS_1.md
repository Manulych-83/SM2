# Skills 1 — результаты проверки

13 сентября 2026. **0.8.32-skills.1**, Godot 4.7.2. Выполнен срез 5000 самостоятельных навыков из [плана масштабирования](CONTENT_SCALING_PLAN.md). Это технический контент, не 5000 готовых игровых занятий/способностей. [Контракт и границы](IMPLEMENTATION_SKILLS_1.md).

## Нагрузочный маршрут

Новый набор skill_scale — **126 проверок**. Каталог содержит 5000 навыков и 8 характеристик, несколько тысяч узлов, источников опыта и прямых вкладов. Все строки собраны общим компилятором пакетов и проверены доменным каталогом. Инструментированный каталог подтверждает, что адресный расчёт выбранного навыка читает ровно два определения: сам навык и его прямой источник прибавки. Результат равен полной проекции.

Проверены сохранение/восстановление разреженных и полных тел, оплата узла двумя направлениями, неизвестные/повторные/несортированные ID, неверные типы XP/layout, исчезновение оплаты и нулевые строки. Малый каталог не принимает новый layout по выбору файла. Проверка тела с практикой во всех направлениях также проходит.

В заключительном маршруте герой начинает с синтетически подготовленной практикой во всех **5008 направлениях**. Затем выполняются реальные переходы, первое сражение с отступлением, возвращение в лагерь, две тренировки и покупка перекрёстного узла, следующее полное сражение и экран итогов. Реальные save/load до, во время и после боя сохраняют точный state_hash. Отдельно новый UI-маршрут проверяет героя без массовой исходной практики, который получает нужные XP реальными командами.

Сохранение после заключительного маршрута имеет **1880666 байт**. У героя в нём записаны все 5008 направлений, у непрокачанных носителей — ноль строк, у спутника остаётся отдельный общий опыт. [Сводка файла](../outputs/skills-1/finished-save-summary.json). Структурный бюджет и предел 8 МиБ не увеличивались. Файл создан в изолированной `.local/skills-1/fully-practiced`, пользовательские сохранения не затрагивались.

Первый проект стенда неверно задал схему awards/ID характеристики; исправлены тестовые данные. Затем тест попытался тренировать обычный навык до первой встречи и получил прежний отказ. Исправлен маршрут, игровое ограничение сохранено. Предварительный UI-запуск не выбирал новый сценарий в таблице инструментов; маршрут выбора исправлен, старые ожидания UI не менялись.
