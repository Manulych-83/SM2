# Проверка контента и масштаба

Все команды выполняются из `E:\GPT\SM2`. Игровые сохранения не используются; runtime и отчёты остаются в проекте.

## Перед запуском нового контента

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/check_content.ps1
```

Проверяются действующие составные загрузчики основной кампании Survival с тканями, каталог развития и ссылки первого похода. Отчёт: `outputs/content-audit/report.json`. Это проверка определений, а не полный игровой тест всех исторических режимов и не проверка художественного качества.

Для отдельного полного JSON-каталога развития:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/check_content.ps1 -ProgressionFile .local/my_progression.json -OutputDirectory outputs/my-content-check
```

Это инструмент проверки, он **не подключает** файл к кампании и не переписывает игровые данные. Вход — полное определение в одном из уже поддержанных форматов `Sm2ProgressCatalog`, не отдельный узел и не `.tres`. Неизвестные поля/версии, нарушенные ограничения и числа по-прежнему отклоняются основным каталогом. Размер входного файла ограничен 8 МиБ.

Примеры диагностик:

| Ошибка | Что показывает отчёт |
| --- | --- |
| Повторный ID | `nodes[1].id`, идентификатор и первое место `nodes[0].id` |
| Нет предпосылки | `nodes[0].requires`, исходный узел и отсутствующий ID |
| Цикл | `cycle_or_dependent`, список заблокированных узлов; включает зависимые от цикла узлы, а не только сам цикл |
| Неверная версия, число, форма | Код действующего валидатора в `validation`; дополнительные подсказки его не заменяют |

Нулевой код завершения означает, что проверки прошли. Ошибка контента и неисправность запуска возвращают ненулевой код; уточнение находится в отчёте/журнале. Прежний принятый каталог при неудачной пересборке сохраняется.

## Измерение масштаба

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/check_foundation.ps1
```

Это длительный диагностический прогон: реальные переходы, повтор истории, запись и чтение настоящего формата кампании. Отчёт: `outputs/foundation-3/latest/report.json`. `passed` означает корректное выполнение стенда. **Готовность к большой кампании** — отдельное поле `ready_for_large_campaign`; причины отказа перечислены в `blockers`. Нулевой код стенда с `ready_for_large_campaign: false` не означает поддержку измеренного масштаба.

Для сравнения времени каждый раз задавайте **новую** папку `-RuntimeRoot`, например `.local/foundation-3/recheck-01`. Существующий слот вызывает дополнительную проверку прежнего сохранения при записи, поэтому повтор в прежней папке измеряет другую нагрузку. Старые runtime не удаляются инструментом. По возможности не запускайте другие проверки одновременно; повторяемость корректности не равна статистической точности времени.

Инструмент измеряет сборку каталогов на 100/1000 узлов и отдельно граф 1000/10000 узлов. Предел полного каталога 1000 сохраняется: успешный граф на 10000 не доказывает поддержку такого дерева экраном, прогрессией или сохранением. Истории состоят из безопасных переходов; длинная история с боями, множеством тел и предметов будет иметь другую стоимость.

Время измеряется на текущем компьютере в одном прогоне каждой нагрузки; это не статистический бенчмарк минимальных системных требований. `static_memory_bytes` — состояние памяти процесса в конце, не пиковая память и не память только каталога. `payload.bytes` — JSON полезных данных без оболочки сохранения. Превышение бюджета дерева проверяется штатным хранилищем; его счётчик после отказа означает нижнюю границу, а не полный размер дерева.

## Правила расширения

1. Новый предмет/узел поддержанного вида проходит существующую схему и общие запросы правил.
2. Новый вид механики получает отдельно согласованный работающий пример, проверку сохранения, интерфейс и обратную связь.
3. Лимиты не повышаются без измерений. Изменение допустимых форматов, архива и сохранений требует явной совместимости; прежние слоты не мигрируются молча.
4. Синтетические нагрузки остаются в `tests/fixtures`; они не становятся балансом или контентом кампании.
