## Проверенные сценарии

- Цена физической атаки, импульса, щита и гибрида совпадает с разрешённым боевым preview. Учтены надбавка генетики к усталости и пси-усилителя к концентрации. Неизвестные участник/способность не получают выдуманную цену. Изменение возвращённых словарей не меняет состояние или RNG.
- Список карточек сохраняет ID боя, действующего участника и ревизию; порядок верхних карточек совпадает с основной и отложенной очередями. Осмотр спутника мышью не передаёт ему ход и не меняет хеш мира.
- Вне дальности кнопка меча отключена, но показывает 4 ОД; наведение выводит доменную причину отказа. После исчерпания ресурса псионика отключается с объяснением. Прогноз настоящего импульса содержит стоимость и повреждение из общего запроса, без изменения состояния.
- Устаревшая карточка после внешней принятой команды отвергается по свежему runner сессии; ресурсы и состояние не меняются, сообщение предлагает выбрать действие заново. При первой проверке обнаружено сравнение с прежним экземпляром runner; исправлено. Провал первого запуска hud/report.json относится к этой итерации, окончательный успешный результат — hud2/report.json.
- Импульс и щит применены мышью через новые карточки; концентрация списывается один раз, щит действительно появляется. Переключение вкладок мышью не меняет игру.
- Настоящие атаки противников создают кровоточащую рану. Панель показывает её конкретную перевязку, карточка расходует материал через прежнюю команду и обнуляет rate выбранной раны. Последующее сохранение/загрузка точно сохраняет состояние.
- Старый M3 проходит прежние выбор клетки, прогноз, реакцию, сохранение/загрузку и итог боя. Проверка battle_feedback проходит плавный переход, остановку отхода ответным ударом, пси-щит, импульс, смену состояний защиты и точное восстановление.
