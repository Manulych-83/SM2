# UI 8 — главное меню

12 сентября 2026, **0.8.14-ui.8**. После продолжения пользователя завершено оформление входа в актуальный поход в общем бронзовом стиле. Базовые полноэкранные 2560×1440, KEEP и scale1.6 сохранены; треугольных украшений нет.

## Поведение

Основные действия: «Поход к руинам · новая игра», «Продолжить сохранённый поход», «Вернуться в начатую игру», дополнительные режимы, выход. Старые примеры тканей/протезов, первого инвентаря и региона перенесены под существующий раскрывающийся раздел вместе с прочими режимами. Их идентификаторы, обработчики и отдельные слоты сохранены.

«Продолжить» доступно при наличии файла survival_tissues и использует прежнюю загрузку кандидата. Наличие файла не объявляется успешной проверкой его содержимого. Ошибка оставляет текущую сессию и показывает прежнее понятное сообщение. «Вернуться» открывает тот же объект Sm2LifeSession без чтения/записи сохранения или шага боя; теперь работает для актуального похода и прежних миров. Ранее эта кнопка принимала только REGION_FORMAT, несмотря на основной запуск Survival. Возврат из меню ведёт в лагерь; идущий бой продолжается через прежнюю кнопку лагеря.

Новая игра, как прежде, заменяет начатую сессию без автоматической записи на диск. Отличие новой игры, загрузки и возврата объяснено рядом с кнопками. Новых подтверждений, автосохранений или слотов не введено.

Справа — описание рабочего маршрута и состояние именно живой сессии, а не превью файла сохранения: место, режим боя/Души, количество законченных встреч. Для прежнего профиля показано отдельное пояснение. Декоративная иллюстрация составлена из существующего атласа; это не внешний вид сохранённого героя и не новое игровое содержимое.

## Ответственность

- `Sm2StartScreen` строит представление, вызывает существующие обработчики Main и читает готовую проекцию `Sm2CampView` для краткой информации.
- `Sm2StartIllustration` рисует статичную композицию из прежних ресурсов `Sm2BattleArt`, не имеет игровой сессии.
- `sm2_main.gd` сохраняет создание и загрузку кандидатов; новая ветка отображения действует только на странице menu. Старый экран отряда и игровые страницы не переоформляются этим этапом.
- Domain, application, игровые каталоги, механики, форматы и слоты не меняются.

Новые механики, журнал, настройки, дополнительные сохранения и дальнейшие этапы не входят. Коммит/публикация отдельно. Проверка — [STATUS_UI_8.md](STATUS_UI_8.md).
