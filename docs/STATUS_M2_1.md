# M2.1 — результат реализации

9 сентября 2026 года. Проект: **E:\GPT\SM2**. Подэтап **M2.1 реализован и проверен** по [контракту](IMPLEMENTATION_M2_1.md).

## Что работает

- Авторское поле 11×7: две поверхности, два камня, шесть клеток высоты 1, шесть стартовых позиций.
- Проверка соседнего шага, цены AP/усталости, подъёма/спуска, препятствий и занятости.
- Достижимость в оставшийся бюджет и отдельный маршрут на несколько активаций; устойчивое разрешение равенства путей.
- Точная симметричная линия видимости с учётом касаний гексов, высот, непрозрачности и участников.
- Командное перемещение с отдельным прогнозом. Ошибочная команда не меняет состояние, ресурсы, RNG, идентификаторы и ревизию.
- Погибшие и вышедшие участники не занимают клетку и не закрывают луч. Это пространственное чтение готовых признаков; саму смерть и бегство M2.1 не рассчитывает.
- Проверка каталога перед публикацией, отделённые входные/выходные данные, возможность добавить поверхность с другой комбинацией стоимости.

## Реальная проверка

Движок: **Godot 4.7.2 stable official**. Финальная чистая копия: `E:\GPT\SM2\.local\m2.1\final-clean-20260909-224331`. До импорта в ней отсутствовал `.godot`.

| Проверка | Результат |
|---|---|
| Импорт чистой копии | Успех; завершён перед тестами |
| Все проверки на чистой копии | **1328 проверок, 0 ошибок, exit 0** |
| Все проверки основной рабочей папки | **1328 проверок, 0 ошибок, exit 0** |
| Прежние unit/integration/scenario M1 | Включены в оба общих прогона; прежние исходники и эталоны не переписаны |
| Новые spatial/m2_content/m2_movement | Пройдены; включая независимые эталоны LOS, маршрут с двумя непохожими ценами, числовые равенства путей, int64 ID, ошибочные входы и отделённость состояния |
| Диагностический прогон на чистой копии | **3 принятых перемещения, exit 0**; конечная клетка (4,2), AP=1, усталость=16 |
| Следующий шаг при AP=1 | Отказ `insufficient_ap`, полный hash состояния прежний |
| RNG после прогона | 0 обращений; прежнее состояние генератора |

Первый запуск проверочной копии не дошёл до импорта: внешний изолированный PowerShell не нашёл установленный движок. Повторный запуск получил явно проверенный путь Godot; затем импорт и проверки прошли. Это отражено в рабочих журналах, не скрыто как успешная первая попытка.

При независимом чтении найден и исправлен граничный случай: общее число записей участников не должно ограничиваться числом клеток, поскольку мёртвые/вышедшие клеток не занимают. Добавлены проверки поля 1×1 с живым и не участвующим бойцом. Правила ожидаемого движения и прежние тесты M1 не менялись ради прохождения.

## Что ещё не сделано

Очередь раундов, Wait, восстановление усталости, реальные атаки/щит/броня, зоны контроля, мораль, бегство и ИИ относятся к оставшимся подэтапам M2. Сохранение полного нового боя ещё не реализовано; `sm2.field_probe` — только диагностический снимок без restore.

Графическое поле и управление мышью — M3. В этом проходе UI не менялся и отдельная визуальная приёмка не выполнялась. Запуск через «Запустить игру.cmd» по-прежнему открывает существующий стартовый экран. Отдельный игровой EXE не пересобирался; новые пространственные проверки запускаются из исходного проекта.

Следующий подэтап: **M2.2 — очередь, раунды, инициатива, восстановление ресурсов и Wait**, затем сохранение соответствующего состояния очереди. Коммитов и публикации не выполнялось.
