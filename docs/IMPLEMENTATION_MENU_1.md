# Menu 1 — главное меню по образцу пользователя

13 сентября 2026. Версия 0.8.39-menu.1. Экран использует прежний оригинальный фон `assets/start_screen/valley.png` без изменений. Новые простые иконки настроек/слотов — отдельные SVG. На основном экране четыре кнопки; база QHD/KEEP/scale1.6 прежняя.

## Поведение

- Крестик справа сверху закрывает игру. Слева от него такая же по размеру кнопка открывает прежние настройки; F10 и пользовательская привязка сохранены.
- Если ни один слот не занят, основная кнопка — «Новое воплощение». Она создаёт новую кампанию в выбранном пустом слоте. Прежнее отсутствие автосохранения сохраняется: записать игру можно в лагере.
- При наличии сохранений основная кнопка — «Продолжить». Она заново определяет последнее доступное сохранение и загружает его с диска. Несохранённая живая сессия не подменяет результат загрузки.
- Выбор последнего сохраняет прежнюю политику: время изменения валидного основного файла либо резервной копии; равные времена разрешаются выбранным слотом, затем порядком индексов. Предварительный осмотр не заменяет полную проверку при загрузке.
- Повреждённые/несовместимые файлы не считаются пустыми слотами. Если доступного сохранения нет, «Продолжить» открывает список с объяснениями; файлы не заменяются новой игрой.
- Под основной кнопкой — реальные номер кампании, место и дата сохранения. В компактном меню дата отображается в часовом поясе ОС с явным UTC-смещением; формат сохранения не меняется. В существующих карточках слотов дата по-прежнему UTC.
- Кнопка слева открывает три слота: выбор, загрузка, новое воплощение в пустом слоте и удаление. Выбор строки не загружает мир. Здесь же доступен возврат к живой игре без загрузки. Закрытие списка и Escape сохраняют текущую сессию.

## Два подтверждения удаления

«Удалить» у конкретного слота открывает первый диалог. Его подтверждение открывает отдельный второй диалог; только «Удалить навсегда» во втором шаге вызывает прежнее файловое удаление. Отмена и Escape на любом шаге ничего не удаляют.

Оба действия привязаны к показанному индексу слота и отпечатку его файлов. На переходе ко второму шагу и при окончательном удалении проверяется неизменность файлов. Изменившееся сохранение остаётся на месте; требуется заново выбрать удаление. Вызов окончательного обработчика без второго шага не выполняет операцию. Подтверждение перекрывает действия списка; список блокирует кнопки основного экрана, включая фокус с клавиатуры.

Удаляются прежние точные основной, `.bak` и `.tmp` файлы только выбранного слота. Общие блоки истории не удаляются. Прежние отказы при папке вместо файла и ограничения файловой атомарности сохранены. После успеха закрывается только живая сессия удалённого слота.

## Совместимость и проверка

Доменные правила, каталоги мира, форматы и физические пути сохранений не менялись. Полное прежнее меню со всеми примерами доступно через `tools/run_game.ps1 -LegacyDemos`; обычный запуск показывает новый экран. Это сохраняет доступ к прежним проверочным режимам без дополнительных кнопок поверх нового макета.

Наборы: `start_menu` (компоновка, загрузка, новое воплощение, резервная копия, повреждения, четыре разрешения), `campaigns` (три мира, двойное подтверждение, отмена, устаревшее удаление), `settings`, `controls`, `expedition`, `creatures`, `sequences`, core `campaigns`. Итоговые результаты и настоящие снимки — `outputs/menu-1/summary.json`. Сборка и её выход по крестику проверяются отдельно. Пользовательские сохранения не используются.
