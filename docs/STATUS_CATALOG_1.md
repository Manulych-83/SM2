# Catalog 1 — проверка первого среза

13 сентября 2026, версия **0.8.31-catalog.1**, Godot 4.7.2. Выполнен первый рабочий срез [согласованного плана масштабирования](CONTENT_SCALING_PLAN.md): пакеты физических предметов, зависимости и происхождение записей, индексированный каталог, авторская проверка и подключение к существующей кампании.

**1949 проверок, все прошли.** Проверены действительные отчёты с passed=true, пустыми failures и числом проверок; скрипты завершились с кодом 0. [Сводка и ссылки на журналы](../outputs/catalog-1/checks.json).

Проверены зависимости, цикл, неизвестный корень, повреждённые поля, отсутствующий файл/массив/ID, дубликат с обоими источниками, изоляция копий, успешная/отклонённая пересборка индекса, типы целых чисел. Первая проверка обнаружила различие int/float после переноса ремонтного комплекта из кода в JSON: устранено явным integer_fields, ожидание прежних данных не ослаблено. Второй запуск обнаружил отсутствие маркера завершения нового набора; маркер добавлен. Заключительный отчёт — checks-20260913-133610-146-0fdf0897.json.

На синтетическом каталоге **10000 разных определений** проверены компиляция пакета, доменные правила, совпадение каждого определения при поиске по ID, а также валидация и точное восстановление инвентаря из **10000 экземпляров разных типов**. 10001-я запись отклоняется без изменения ранее принятого каталога. Пропавшая ссылка на ресурс лечения также отклоняется.

В заключительном одиночном замере компиляция и построение каталога заняли **97,394 мс**, получение и сравнение всех 10000 определений — **16,524 мс**. Это времена операций стенда, без обещания такого времени открытия интерфейса/сохранения всей кампании; сравнение скорости всей игры до/после не проводилось.

Авторская проверка прошла как для основного набора, так и с явным ItemManifestFile: [обычный отчёт](../outputs/catalog-1/audit/report.json), [явный манифест](../outputs/catalog-1/audit-explicit/report.json). Эти проверки собирают реальный контент кампании и проверяют доменные ссылки; происхождение каждого определения доступно в отчёте.

## Сборка

Экспорт `tools/export_game.ps1 -RuntimeRoot .local/catalog-1/export` — код 0. Журнал export-20260913-133919-247-b39b37b3.log. [Версия, SHA256 и результаты запусков](../outputs/catalog-1/build.json).

Упакованные ресурсы проверены через builds/SM2.exe: старый завершённый поход, сохранение с .bak, архивный итог после второго воплощения, новая кампания, экран развития, новый бой с компактным профилем, накопление XP и точное сохранение/загрузка. Затем выполнен отдельный запуск EXE на 120 кадров. Оба запуска — код 0 без ошибок Godot; журналы [pack.log](../outputs/catalog-1/pack.log) и [exe.log](../outputs/catalog-1/exe.log). Снимок старого завершённого похода просмотрен; оформление не менялось. Полный набор UI-проверок заново не запускался.

Использованы только изолированные тестовые копии сохранений внутри .local/catalog-1, пользовательские кампании не изменялись. Сценарий проверки сборки сохранён в outputs/catalog-1/export_smoke.gd.

## Что ещё не выполнено

Пакетами пока управляются физические предметы. 5000 самостоятельных навыков, 2000 статусов и 3000 типов врагов вместе не проверены и не объявляются поддержанными. Крупные каталоги других видов, общие операции, возможности, шаблоны существ, миграции контента и совместная приёмка остаются в плане. Лимиты экземпляров/сохранений и полное копирование мира прежние; стенд инвентаря не доказывает сохранение 10000 предметов обычным профилем кампании. UI этого объёма не принят.

Следующий срез — каталог развития и самостоятельные направления навыков, с учётом существующих индексов и ограничений связей/опыта. После подготовки архитектуры возвращаемся к визуальной сцене; перед этапом 5 пользователь вручную осматривает игру и согласует продолжение. Коммит и публикация не выполнялись.
