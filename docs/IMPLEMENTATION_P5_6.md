# P5.6 — основной экран игры

После подтверждения продолжения выбран ограниченный шаг представления: сделать актуальную игру основным входом, сохранив доступ к прежним самостоятельным режимам. Новые игровые механики, правила мира, сохранения и содержание P5.5 не меняются.

## Действия

- «Новая игра» (NewImplantButton) вызывает прежний _start_implants(false). Создаёт новую сессию P5.5 в памяти; существующее сохранение не перезаписывается до явной команды сохранения.
- «Продолжить» (ContinueImplantButton) вызывает _start_implants(true). Доступность определяется наличием прежнего p5_implant_journey в user://implant_journey. Ошибочный файл показывает ошибку и не заменяет прежнюю сессию.
- «Вернуться в игру» (ResumeMainButton) доступно только для существующей сессии IMPLANT_FORMAT. Возвращает тот же объект без чтения/записи файла, восстановления ресурса, перехода очереди или начисления опыта. Возврат сначала открывает лагерь; из него можно вернуться в текущий бой.
- «Дополнительные режимы» (OtherModesButton) раскрывает/скрывает две группы прежних режимов. Их кнопки, обработчики и отдельные слоты сохранены. Положение раскрытия сохраняется в текущем окне, новая программа начинает со свёрнутого раздела. Выйти можно из основного меню.

## Архитектура и совместимость

Меняется только Sm2Main. Прежнее построение списка вынесено в _build_other_modes; основное меню отделено от него. Данные игрового мира, команда NewGame, формат17, каталоги, Session/Runner/AI и файлы сохранений не менялись. Новый слот, миграция, автоматическое сохранение и переписывание содержимого старой игры не вводятся.

Пояснения на экране относятся к уже работающему примеру: практическое развитие, генетика/кибернетика/псионика, герой/спутник, лагерь и воплощение. Это не обещание реализованной большой кампании или окончательной анатомии.

## Приёмка

Реальный ввод: компактный старт при1000×700 и1280×800; основные кнопки доступны без прокрутки; раскрытие/скрытие; запуск и продолжение прежнего режима; различие отдельного сохранения и текущей памяти; неподходящая сессия не подставляется под основной возврат; возврат в бой без изменения состояния; повреждённый файл не уничтожает живую сессию; свежая программа продолжает с диска; новая игра не пишет прежний файл. Проверяются исходное окно и готовая сборка.

UI-наборы наследуют помощник реального нажатия, который сначала раскрывает скрытый раздел. В M1 границы проверяются для видимых элементов вне прокручиваемого содержимого и для самой области прокрутки — как в существующих M3/P3. Это изменение проверки геометрии, не отмена доступности старых режимов.

Из-за отсутствия изменений правил боя достаточны чистый импорт, архитектура/unit, p5_implants и интеграционные UI-прогоны актуального и прежних режимов; весь исторический набор не обязателен для этой правки представления. Следующие механики отдельно.
