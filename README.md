# SM2

Одиночная тактическая RPG на Godot/GDScript. Текущая версия **0.8.41-inventory.1**.

## Запуск

Дважды нажмите **«Запустить игру.cmd»**. Базовый режим — полный экран 2560×1440; параметры изображения и клавиши доступны в настройках.

Основная игра — поход за медикаментами: отправиться в руины, завершить первую встречу, найти четыре медикамента и доставить именно найденные вещи в сундук лагеря. Сохраняйте поход через игровые команды; меню поддерживает три кампании.

Мирный экран открывается как походная стоянка: разделы слева, место и цель справа, занятия снизу. «Карта мира» открывает маршруты, «Местные занятия» — доступные действия. Escape возвращает с этих страниц в лагерь. Фон меняется по месту; фигура показывает настоящее снаряжение, сундук остаётся в своей локации. Отдых и ремесло пока недоступны. [Границы первого варианта](docs/IMPLEMENTATION_CAMP_1.md).

Новые кампании используют шаблоны противников с полноценными человеческими телами и физическими вещами. Старые сохранения продолжаются по прежним правилам. Чтобы увидеть новый вариант, создайте кампанию в свободном слоте. [Подробности](docs/IMPLEMENTATION_CREATURES_2.md).

Главное меню: «Продолжить» загружает последнее доступное сохранение. Когда слотов с сохранениями нет, вместо неё появляется «Новое воплощение». Кнопка слева открывает три слота; удаление требует двух подтверждений. Настройки и выход — вверху справа. Возврат к текущей игре без загрузки доступен в окне слотов. [Подробности](docs/IMPLEMENTATION_MENU_1.md).

## Разработка и проверки

При продолжении с другого аккаунта начать с [передачи разработки](docs/HANDOFF.md). [Готовое задание для нового чата](docs/NEXT_ACCOUNT_TASK.md). Исходники последних экранов и передача включены в коммит версии 0.8.41-inventory.1; локальные сохранения и EXE хранятся отдельно от Git.

Начало работы: [текущий статус](docs/CURRENT_STATE.md), [план](docs/DEVELOPMENT_ROADMAP.md), [правила](AGENTS.md), [карта проверок](docs/TESTING_POLICY.md).

Полное прежнее меню и демонстрации (включая составные воздействия и встречи из шаблонов) доступны отдельным запуском:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/run_game.ps1 -LegacyDemos
```

Без этого параметра запускается обычное меню. Код, данные, форматы и проверки старых примеров сохранены. Исторические инструкции по ним — [в архиве](docs/archive/README_BEFORE_WORKFLOW_1.md).

Все локальные служебные файлы находятся внутри проекта: `.local/` — runtime/логи/временные проверки, `.godot/` — кэш Godot, `builds/` — экспорт. Они исключены из Git. Исходники, контент, документация и выбранные итоговые отчёты хранятся в репозитории.

Проверки больших каталогов пока не означают готовность всей огромной кампании. Точные границы перечислены в [текущем статусе](docs/CURRENT_STATE.md).
