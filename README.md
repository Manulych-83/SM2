# SM2

Одиночная тактическая RPG для Windows на Godot 4.7.2 и типизированном GDScript. Тактическая основа развивается от Battle Brothers. Целевая игра — путь бессмертной Души «от пещерного человека до бога» в сохраняющемся мире, где одновременно существуют первобытные общества и технологические анклавы.

Душа вселяется в свежий труп чистого человека без улучшений. Герой и управляемые спутники осваивают мир; практическое развитие нового воплощения начинается заново, знания Души сохраняются. Каждая характеристика и навык получают собственный опыт: он автоматически повышает уровень, а неизрасходованный остаток используется для покупки узлов без снижения уровня. Генетика, кибернетика и псионика — три сочетаемых пути развития.

**Текущая игра — 0.5.4-p4.1: постоянное снаряжение и последовательные встречи.** Откройте «Путь героя»: передавайте оружие и броню, складывайте их в тайник и проходите три встречи с текущими здоровьем и развитием. После воплощения новый герой может забрать прежние вещи и снова сражаться. Без оружия доступен кулак. Снаряжение меняется только вне боя. Старый пример «Мир и воплощение», лаборатория и прежние бои доступны отдельно. Контракт — [IMPLEMENTATION_P4_1.md](docs/IMPLEMENTATION_P4_1.md), приёмка — [STATUS_P4_1.md](docs/STATUS_P4_1.md).

## Как проверить развитие в бою

Откройте «Запустить игру.cmd» → **«Бой с развитием»**. Синими героем и спутником управляете вы; красными — ИИ. Подведите своего бойца к противнику и ударьте мечом. Попадание, промах и ответный удар дают опыт только самому действующему бойцу. Новые уровни влияют на последующие действия.

Кнопка **«Развитие»** на поле открывает опыт и узлы выбранного союзника. После завершения боя можно изучить доступные узлы; уровень и продвижение сохраняются. Нажмите «Сохранить», чтобы записать бой и развитие вместе. После перезапуска нажмите **«Продолжить» рядом с «Бой с развитием»**. Новый пример не перезаписывает сохранение автоматически. Числа наград и боевых прибавок пока пробные.

## Как проверить развитие

Откройте «Запустить игру.cmd» → **«Лаборатория развития»**. Выполните четыре упражнения с мечом: сила станет уровня 11, ближний бой — уровня 2, псионика останется без опыта. Изучите «Крепкую основу» и «Постановку удара»: доступный опыт уменьшится, уровень и продвижение сохранятся. Итоговые значения будут 12 для силы и 10 для ближнего боя с учётом прибавки силы.

Нажмите «Сохранить». После перезапуска откройте лабораторию и нажмите «Загрузить». «Новый пример» начинает другой учебный пример, не перезаписывая сохранение. Числа и четыре простых узла — проверочный набор, а не баланс будущей кампании.

## Как открыть текущую игру

1. В папке E:\GPT\SM2 дважды щёлкните **«Запустить игру.cmd»**.
2. Нажмите **«Бой по области»**. «Бой с магией», «Бой с эффектами» и «Начать сражение» открывают прежние варианты.
3. Наводите мышь для прогноза. Щелчок по свободной достижимой клетке перемещает бойца; по врагу — применяет выбранную или основную атаку.
4. Для **«Чародейского взрыва»** выберите кнопку способности, затем центральный гекс. Радиус 1, цена 5 AP / 10 усталости / 12 маны; поражаются только противники. ИИ также использует области.
5. «Ждать» откладывает ход, «Конец хода» передаёт его дальше. Правая кнопка отменяет ещё не выполненный маршрут и выбор действия.
6. «Сохранить» записывает бой. После перезапуска выберите **«Продолжить бой по области»** либо соответствующее продолжение прежнего режима.

Синие — ваш отряд, красные — противник. Золотое кольцо отмечает активного бойца. «Создать отряд» открывает отдельный технический экран M1, ещё не связанный с составом сражения. Новая игра не перезаписывает слот автоматически. Редактор открывать не требуется; первый запуск подготавливает ресурсы.

Названия «магия», «мана» и arcane пока принадлежат прототипам M4. Будущий смысл сверхъестественных способностей — псионика; её окончательные правила и переименование старых данных не выполнялись. Числа демонстраций не являются финальным балансом.

## Сохранения и проверки

Рекомендуемый CMD хранит данные, кеши и временные файлы Godot внутри .local/runtime. Прямой запуск EXE без инструментов проекта использует обычное окружение Windows; для пользовательского запуска используйте CMD. Все проверки через инструменты выполняются с отдельным RuntimeRoot внутри проекта, не в игровых сохранениях.

| Режим | Путь внутри .local/runtime/appdata/SM2/ |
|---|---|
| Бой с развитием P2 | development/p2_development_run.json |
| Мир и воплощение P3 | world/p3_world.json |
| Развитие P1 | progression/p1_lab.json |
| Области M4.4 | areas/m4_area_run.json |
| Магия M4.2–M4.3 | magic/m4_magic_run.json |
| Эффекты M4.1–M4.3 | effects/m4_effects_run.json |
| Обычный бой M3 | battles/m2_ai_run.json |
| Технический отряд M1 | saves/session.json |

- **«Проверить проект.cmd»** запускает автоматические проверки.
- Отдельные проверки интерфейса — tools/run_ui_checks.ps1; набор области — m4_areas.
- Журналы инструментов — .local/logs, сборка — builds/SM2.exe.
- Последняя приёмка — [STATUS_P3.md](docs/STATUS_P3.md), контракты — [IMPLEMENTATION_P3.md](docs/IMPLEMENTATION_P3.md). Лаборатория — [STATUS_P1.md](docs/STATUS_P1.md); история областей — [STATUS_M4_4.md](docs/STATUS_M4_4.md).
- Настройка Godot, запуск и обновление сборки — [LAUNCH_AND_CHECKS.md](docs/LAUNCH_AND_CHECKS.md).

P1, P2 и P3 имеют отдельные слоты и форматы. Старые боевые сохранения не мигрируют автоматически; отчёты M0–M4.4 и P1 сохраняют исторические результаты.
