# Предложение компоновки боевого интерфейса

12 сентября 2026. После обсуждения пользователь попросил сделать макет и посмотреть. Это **визуальное предложение**, не утверждение окончательной компоновки и не замена рабочего интерфейса.

Два нативных снимка Godot 2560×1440 при рабочем масштабе 1.6:

- `01-overview-2560.png` — очередь сверху по центру, постоянный отряд слева, активный герой снизу слева, компактные действия снизу, завершение хода справа. Контекстная карточка скрыта.
- `02-target-2560.png` — тот же момент боя, выбран пси-импульс; справа цель и настоящий прогноз, рядом с целью краткая подсказка.

Поле, фигуры, портрет и материалы — существующие ресурсы SM2. Два союзника и два противника, ресурсы, цена и повреждение импульса взяты из новой локальной сессии Survival 3. Способности изучены обычными командами практики и покупки узлов; переход в руины и начало боя тоже обычные. Снимки не меняют состояние этой встречи, пользовательские сохранения не используются. Повторяющиеся портреты являются нынешними временными ассетами.

Группы прицельных ударов, настройка панели, горячие клавиши 1–7 и категории — предложения интерфейса. На макете это рисунок из Godot Controls, а не действующие кнопки. Значки оружия показывают места действий; доступность каждой физической атаки по дальности здесь не является проверенным интерактивным состоянием. Перевязка показана приглушённой: кровотечения в этой сцене нет. Не вводятся инвентарь в бою, смена снаряжения, новый тип ресурса или новые правила повреждений. Сводное состояние цели не заменяет анатомию.

`layout_mockup.gd` воспроизводит оба снимка через установленные Godot и проект. `report.json`: 19 проверок подготовки, доступности показанного пси-импульса, точного размера изображений, записи и неизменности сессии; не приёмка интерактивного интерфейса. `preview-state.json` содержит использованный снимок состояния и прогноз. Визуально проверены оба PNG после устранения повторяющейся подписи легенды.

Рабочие исходники, конфигурация, сборка EXE и версия игры не менялись. Для внедрения этой компоновки нужно отдельно согласовать результат. Все новые материалы этого шага — здесь; изолированное окружение запуска — `.local/layout-preview`.
