# Предложение «Тело и инвентарь»

12 сентября 2026. Пользователь согласовал подготовку макета, чтобы оценить компоновку до внедрения. Две нативные отрисовки Godot **2560×1440** с рабочим масштабом 1.6:

- `01-inventory-2560.png`: постоянный отряд, сводка героя, фигура с фактически надетым снаряжением, вещи, контейнеры, описание перевязочного материала и назначение переноса.
- `02-body-2560.png`: тот же герой, вкладка тела, список частей, выбранная правая рука и отдельные кожа/мышцы/кость. Перевязка приглушена, поскольку раны нет.

Это **макет из неинтерактивных Godot Controls**, а не обновление рабочего интерфейса. Кнопки, вкладки, поиск, сортировка, группировка трёх перевязочных материалов и новая компоновка ещё не подключены. Специальное сравнение экипировки здесь не показано. Инвентарь, размер и объём предметов не превращаются в пространственную сетку: карточки показывают список. Единицы объёма оставлены текущими условными, не переименованы в литры. Общий предел переносимой массы не выдуман: показана фактическая масса тела с вещами, а пределы — для конкретного контейнера.

`inventory_mockup.gd` открывает новую локальную Survival 3 и читает `Sm2SurvivalWorkspaceView`. Текущее состояние: 11.85 кг, кровь 5000/5000 мл, без ран; карманы 0/4, пояс 3/6, рюкзак 0/40. Три предмета перевязки находятся в поясе. Доступность переноса одного реального ID в рюкзак проверяется через существующий `world.check`. Перенос не выполняется. `evidence.json` сохраняет отделённые данные и подтверждает неизменность сессии.

Фигура снаряжения собрана существующим `Sm2BattleArt` из реальных надетых определений. На вкладке тела надетые слои лишь скрыты в представлении для осмотра, сами вещи не снимаются. Окружность руки — иллюстративная отметка, не готовая карта интерактивных зон или модель тканей. Новая анатомическая иллюстрация и отдельные лица не созданы. Иконки контейнеров — простые новые SVG внутри этой папки; остальные изображения прежние. Треугольные украшения рамок отсутствуют.

`report.json`: 137 успешных проверок подготовки, чтения ресурсов, разрешённости показанного переноса, границ подписей, размеров PNG и неизменности сессии. Это не тесты готового управления. Оба макета просмотрены; у длинной подписи слота брони использовано сокращение. Прогон после замены временных значков — `render-final.log`, код 0.

Производственные файлы, версия и EXE не менялись. Сохранения пользователя не открывались. Временное окружение — `.local/inventory-layout`. Дальнейшее внедрение после согласования макета; коммит/публикация не выполнялись.
